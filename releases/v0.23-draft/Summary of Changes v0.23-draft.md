# Summary of Changes — v0.23-draft

Article 3 (Thoroughfares): one subject only — making it unmistakable that **listing a driveway in
the Inventory does not turn it into a road, and does not require anyone to improve anything.**
Builds on v0.22-draft.

This release responds to a concern raised at the public meeting: that a driveway carried in the
Town's E-911 road data under a road name, and therefore listed in the Inventory with a Type such
as R2 or R3, might have to be built to that standard.
It does not, and it never did. The protections were already in the Code — but they sat in three
different sections, apart from the Inventory itself. This release puts the answer alongside the
Inventory, and adds the one sentence the Code was genuinely missing.

## A driveway stays a driveway

A new provision states the rule directly, in the Driveways section:

> An access way that serves no more than two single-family dwellings, or one two-family dwelling,
> **is a Driveway and remains a Driveway** — regardless of the Type recorded for it in the
> Inventory, the name under which it appears there or in the Town's E-911 data, or the fact that
> it is listed at all.

No Street or Road standard reaches such an access way unless and until it is expanded past the
driveway limit. Listing it records, **in advance**, the standard that would apply *if* that ever
happens — it does not convert a driveway into a road. The same point is repeated on the Driveway
page in the Types section, so a reader who starts there finds it too.

The Code previously said, twice, what makes something *stop* being a driveway. It never said what
**keeps** it one. That was the missing sentence.

## The Inventory now shows what a segment is today

The Inventory records a new piece of reference information: **present use** — whether a segment
functions today as a driveway rather than as a street or road.

Segments recorded as driveways now appear in the Inventory table with the Type **D**, in a neutral
colour of their own, and the Type they *would* take if they were ever expanded past the driveway
limit appears in a separate column headed **"On conversion."** The Type Map draws them the same
way, with their own legend entry. Previously the table had only one status column, which had to do
double duty — present tense for a real road, future tense for a driveway — with no way to tell
which one you were reading.

Four segments are recorded as driveways in this draft: **Barrol Point Road, Gastaldo Farm Road,
Mandys Way, and Spruce Road.** Review of the remaining segments continues, and more may be recorded
in later drafts.

Recording this is **descriptive only.** Whether an access way is a driveway is decided by the rule
above — by how many homes it serves — and not by what the Inventory says about it. A segment that
has not yet been reviewed, or that is recorded incorrectly, is protected in exactly the same way.
Nothing turns on the Town completing this record.

## Plainer language where it was being misread

- The heading over the Inventory's Type column read **"Classification (binding)."** In the Code
  that word distinguishes the column that governs from the columns that are merely reference
  information. Read on its own, next to a person's own road, it sounded like *you are bound to do
  this.* It now reads **"Classification (governing),"** and says plainly that it means which column
  controls, and that it requires no work on any segment.
- The note printed above the Inventory table has been rewritten in plain language. It now opens
  with the point that matters — **being listed here does not require anyone to do anything** —
  explains the D and "On conversion" columns, and states that segment names come from the Town's
  E-911 data and reflect **addressing, not regulatory status.** The Type Map's note now says the
  same.

## A gap closed, and a protection made explicit

Two related fixes for ways that already serve more than two homes:

- **A way already serving three or four homes may continue as it is, indefinitely.** No improvement
  is required of it because of this Article. This was already the effect of the Code; it is now
  stated outright rather than left to be pieced together.
- **Adding another home to such a way now triggers the improvement duty.** Previously the trigger
  was written to catch only a *driveway* that grew past the limit — so a way already above the
  limit, which was never a driveway, fell between the two rules and triggered nothing. The trigger
  now also applies when a way already above the limit is expanded to serve more homes. As before,
  three or four homes require only the safety-critical items, and five or more require the full
  standard.

## Corrections to the Type of specific roads

- **Gastaldo Farm Road**, **Ledge Hill Crossing**, and **Holstein Lane** are now **Rural Lane
  (R3)** rather than Rural Road (R2). R3 is the *lighter* of the two standards — a narrower gravel
  way and a narrower right-of-way — so this **reduces** what could ever be required of them.
- **Barrol Point Road**, **Mandys Way**, and **Spruce Road** are recorded as **R3** on conversion,
  and as driveways today.

## What did not change

No standard, dimension, or requirement was made stricter anywhere in this release. Nothing in it
requires any existing road or driveway to be improved. The ten Thoroughfare Types and their
standards are unchanged.
